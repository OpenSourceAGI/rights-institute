The comparison guides have grown, so they are now grouped by category, each
with its own card on the [homepage](/):

- **[Dev Tools](/docs/comparisons/dev-tools/all-dev-tools)** — AI code
  editors, text editors, frameworks, UI libraries, docs libraries and training
  datasets.
- **[Services](/docs/comparisons/services/cloud-compute)** — cloud compute,
  storage and databases, payments, domains, internet providers, identity and
  SMS verification, brokers and job platforms.
- **[AI Intelligence](/docs/comparisons/intelligence/ai-language-intelligence)**
  — language, visual and voice models, AI researchers, agent harnesses,
  personas, and marketing and sales AI.

Every guide is also listed in the docs sidebar under **Comparisons**.
