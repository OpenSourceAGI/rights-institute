---
title: Tech Stack
description: The frameworks and services the site is built on.
---

| Layer | Technology |
|---|---|
| Framework | Next.js (App Router) on [vinext](https://www.npmjs.com/package/vinext) + Vite |
| Styling | Tailwind CSS v4 + shadcn/ui |
| Runtime | Cloudflare Workers |
| Database | Cloudflare D1 (SQLite) / Turso (libSQL) via Drizzle ORM |
| Auth | [better-auth](https://www.better-auth.com) + Google OAuth + Google One Tap |
| Docs | [Fumadocs](https://fumadocs.dev) (this site) |
| Smart Contracts | Solidity (ERC-20) |
| Animations | Canvas API, WebGL, Three.js, GSAP |
| Package Manager | pnpm / bun |
